O MarioGames_Review é um banco de dados para avaliação de jogos. A proposta é criar um sistema em que cada jogo possa ter várias avaliações e pertencer a uma ou mais plataformas. Além disso, será possível adicionar jogos, avaliações e outras funcionalidades relacionadas ao gerenciamento e à avaliação de jogos.
