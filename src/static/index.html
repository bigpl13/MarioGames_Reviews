MarioGames_Review - API

Esta página apresenta as rotas disponíveis no sistema.

As informações abaixo descrevem os endpoints da API.

Teste a rota /hello

Avaliação

Método Exemplo Descrição Resultado
GET GET /avaliacao Listar todas as avaliações.
[ { "id": 1, "texto_avaliacao": "Jogo muito bom!", "data_avaliacao": "2020-10-11", "jogo": "Super Mario Odyssey" }, { "id": 2, "texto_avaliacao": "Excelente jogo!", "data_avaliacao": "2021-05-20", "jogo": "Super Mario Odyssey" }, ... ]
GET ID GET /avaliacao/:id Buscar uma avaliação pelo ID.
{ "id": 1, "texto_avaliacao": "Jogo muito bom!", "data_avaliacao": "2020-10-11", "jogo": "Super Mario Odyssey" }
POST POST /avaliacao Cadastrar uma nova avaliação. O ID é gerado automaticamente. É necessário informar o texto da avaliação, a data da avaliação e o ID de um jogo válido. A data da avaliação deve ser igual ou posterior à data de lançamento do jogo e não pode ser posterior a 2026-08-27.
{ "texto_avaliacao": "Jogo legal", "data_avaliacao": "2020-10-11", "jogo_id": 1 }
PUT PUT /avaliacao/:id Atualizar uma avaliação pelo ID. O ID é informado na URL. Nesta rota, somente o texto da avaliação é alterado.
{ "msg": "Avaliação atualizada", "avaliacao": { "id": 1, "texto_avaliacao": "Jogo excelente!", "data_avaliacao": "2020-10-11", "jogo_id": 1 } }
DELETE DELETE /avaliacao/:id Excluir uma avaliação pelo ID.
{ "msg": "avaliação deletada!", "avaliacao": { "id": 1, "texto_avaliacao": "Jogo legal", "data_avaliacao": "2020-10-11", "jogo_id": 1 } }

Plataforma

Método Exemplo Descrição Resultado
GET GET /plataforma Listar todas as plataformas.
[ { "id": 1, "nome": "PC" }, { "id": 2, "nome": "Console" }, { "id": 3, "nome": "Nintendo Switch" }, ... ]
GET ID GET /plataforma/:id Buscar uma plataforma pelo ID.
[ { "id": 1, "nome": "PC" } ]
POST POST /plataforma Cadastrar uma nova plataforma. O ID é gerado automaticamente.
{ "nome": "Nintendo Switch" }
PUT PUT /plataforma/:id Atualizar uma plataforma pelo ID. O ID é informado na URL. É necessário enviar apenas o novo nome.
{ "msg": "plataforma editada!", "plataforma": { "id": 1, "nome": "Nintendo Switch" } }
DELETE DELETE /plataforma/:id Excluir uma plataforma pelo ID. Os jogos vinculados à plataforma também são excluídos.
{ "msg": "plataformas e jogos da plataforma deletados!", "jogos": [ { "id": 1, "nome": "Super Mario Odyssey", "data_lancamento": "2017-10-27", "plataforma_id": 1 }, { "id": 2, "nome": "Super Mario Odyssey 2", "data_lancamento": "2017-10-27", "plataforma_id": 1 }, { "id": 3, "nome": "Super Mario Odyssey 3", "data_lancamento": "2017-10-27", "plataforma_id": 1 } ], "plataforma": { "id": 1, "nome": "Nintendo Switch" } }

Jogo

Método Exemplo Descrição Resultado
GET GET /jogo Listar todos os jogos.
[ { "id": 1, "nome": "Super Mario Odyssey", "data_lancamento": "2017-10-27", "plataforma_id": 1, "plataforma": "Nintendo Switch" }, { "id": 2, "nome": "God of War", "data_lancamento": "2018-04-20", "plataforma_id": 2, "plataforma": "PlayStation 4" }, ... ]
GET ID GET /jogo/:id Buscar um jogo pelo ID.
[ { "id": 1, "nome": "Super Mario Odyssey", "data_lancamento": "2017-10-27", "plataforma_id": 1, "plataforma": "Nintendo Switch" } ]
POST POST /jogo Cadastrar um novo jogo. O ID é gerado automaticamente. É necessário informar o nome, a data de lançamento e o ID de uma plataforma válida. A data deve estar entre 1958-10-30 e 2026-08-27.
{ "nome": "Super Mario Odyssey", "data_lancamento": "2017-10-27", "plataforma_id": 1 }
PUT PUT /jogo/:id Atualizar um jogo pelo ID. O ID é informado na URL. É necessário enviar o novo nome e o ID de uma plataforma válida. A data de lançamento não é alterada.
{ "msg": "jogo atualizado", "jogo": { "id": 1, "nome": "Super Mario Odyssey", "data_lancamento": "2017-10-27", "plataforma_id": 1 } }
DELETE DELETE /jogo/:id Excluir um jogo pelo ID.
{ "msg": "jogo deletado!", "jogos": { "id": 1, "nome": "Super Mario Odyssey", "data_lancamento": "2017-10-27", "plataforma_id": 1 } }
