MarioGames_Review - API

Esta página apresenta as rotas disponíveis no sistema.

As informações abaixo descrevem os endpoints da API.

Teste a rota /hello

Avaliação

Método Exemplo Descrição Resultado
GET GET /avaliacao Listar todas as avaliações.
[ { "id": 1, "texto_avaliacao": "Eros fez um teste", "data_avaliacao": "2000-10-11", "jogo": "Eros" }, ... ]
GET ID GET /avaliacao/:id Buscar uma avaliação pelo ID.
{ "id": 1, "texto_avaliacao": "Eros fez um teste", "data_avaliacao": "2000-10-11", "jogo": "Eros" }
POST POST /avaliacao Cadastrar uma nova avaliação. Avaliação tem seu conteudo, data válida (maior ou igual a data de lançamento do jogo) e o id de um jogo válido
{ "id": 1, "texto_avaliacao": "Jogo legal", "data_avaliacao": "20010-10-11", "jogo": "God of War" }
PUT PUT /avaliacao/:id Atualizar uma avaliação. Atualização tem seu conteudo, data válida (maior ou igual a data de lançamento do jogo) e o id de um jogo válido
{ "msg": "Avaliação atualizada" }
DELETE DELETE /avaliacao/:id Excluir uma avaliação pelo ID.
{ "msg": "Avaliação excluída" }

Jogo
